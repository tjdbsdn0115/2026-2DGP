# 교수님께 제출할 구현 설명

LEC08의 pico2d 예제를 참고하여 `animation_viewer.py`를 작성했습니다.
이미지는 기존 강의 PNG 대신 AI로 새로 만든 모험가 캐릭터의 Sprite Sheet를 사용했습니다.
대기 4프레임, 걷기 8프레임, 점프 6프레임, 공격 6프레임으로 최소 4종을 구현했습니다.

캐릭터는 960×720 화면 중앙에서 3배 확대 재생됩니다. 모든 자세의 실제 그림 높이는
화면 높이의 절반 이상이며 가장 작은 자세도 396픽셀입니다. 각 동작을 정확히 5회
반복한 후 마지막 프레임에서 1초 정지합니다. 이후 다음 동작을 재생하며,
마지막 공격 뒤에는 첫 대기로 돌아가 순서를 무한 반복합니다.

추가 점수 기능으로 프레임마다 서로 다른 크기의 사각형을 지원합니다.
PNG에서 각 그림의 좌표와 폭, 높이를 확인하여 `clip_draw()`에 개별 전달합니다.
동작별 프레임 수도 4, 8, 6, 6개로 서로 달라서 고정 프레임 수를 가정하지 않고
각 동작의 프레임 목록을 순서대로 재생하도록 구현했습니다.

AI는 새 캐릭터 스프라이트 생성, 프레임 경계 확인, 간단한 반복문 기반 코드 작성,
반복·정지·종료 동작 검증에 활용했습니다. 기존 강의 이미지를 새로 제작했다고
주장하지 않으며 최종 실행 파일에서는 기존 PNG를 불러오지 않습니다.

최종 실행에는 `animation_viewer.py`와 `adventurer_sheet.png`만 필요합니다.
커밋별 코드와 제목, Git 기록 파일은 결과 폴더의 별도 자료에 있습니다.
