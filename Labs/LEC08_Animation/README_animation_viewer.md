# Drill #8 — 간단한 애니메이션 뷰어

`animation_viewer.py`는 75줄입니다. LEC08의 `load_image()`와 `clip_draw()`,
`clear_canvas()` / `update_canvas()` / `delay()` 방식에 `for`와 `while` 반복문을
사용했습니다. 클래스, JSON, 별도 아틀라스 생성 도구는 실행에 필요하지 않습니다.

## 실행

Python 3.10 이상과 pico2d를 사용합니다. 이번 작업에서 Windows와
Python 3.14.7, pico2d 1.5.1로 실제 실행을 확인했습니다.

```powershell
python -m pip install pico2d==1.5.1
python C:\2DGP12\Labs\LEC08_Animation\animation_viewer.py
```

VS Code에서 `animation_viewer.py`를 열고 Python 실행 버튼을 사용해도 됩니다.
PNG는 소스 파일 기준 경로로 불러오므로 터미널의 현재 폴더와 무관하게 실행됩니다.
ESC 또는 창의 닫기 버튼으로 종료합니다.

## 스크린샷 요구 조건

| 요구 조건 | 구현 |
|---|---|
| 적절한 Sprite Sheet 준비 | AI로 새로 만든 `adventurer_sheet.png`, 1536×1024 RGBA |
| 최소 4종 애니메이션 | 대기, 걷기, 점프, 공격 |
| 캐릭터 확대 표시 | 960×720 화면에서 3배 확대, 가장 작은 실제 그림 높이 396px |
| 소스 파일명과 폴더 | `Labs/LEC08_Animation/animation_viewer.py` |
| 화면 중앙 재생 | 모든 프레임을 (480, 360)에 출력 |
| 각 동작 5회 반복 | `for repeat in range(REPEAT_COUNT)` |
| 이후 1초 정지 | 마지막 프레임을 유지하며 `show_for(..., PAUSE_SECONDS)` |
| 차례대로 무한 반복 | `while True`에서 대기 → 걷기 → 점프 → 공격 순서 반복 |
| 프레임마다 다른 크기 | 각 프레임의 실제 (x, y, 폭, 높이)를 개별 사용 |
| 동작마다 다른 프레임 수 | 4, 8, 6, 6개 프레임을 목록 길이대로 재생 |

원본 강의 PNG 파일들은 참고 자료로 저장소에 남아 있지만 최종 뷰어에서는
불러오지 않습니다. 새로운 캐릭터의 모습과 프레임 이미지는 내장 ImageGen으로
생성했습니다. PNG의 알파 채널을 확인해 모든 프레임 경계를 맞췄으며,
이웃 캐릭터의 일부가 잘려 들어오지 않도록 공격 프레임 간격을 수정했습니다.

## 코드 읽는 순서

1. `animations`: 동작 이름, FPS, 프레임 좌표 목록입니다.
2. `draw_frame`: PNG의 위쪽 기준 좌표를 pico2d의 아래쪽 기준으로 바꾸고 중앙에 확대 출력합니다.
3. `show_for`: 한 프레임을 지정 시간 동안 유지하면서 종료 입력을 확인합니다.
4. `main`: 각 동작을 5회 재생하고 1초 정지하는 순서를 무한 반복합니다.

시간을 재는 `perf_counter()`는 단순한 시계입니다. 1초 정지 중에도 종료 입력을
확인하기 위해 최대 0.01초씩 나누어 기다립니다. 종료 시 `finally`에서 캔버스를 닫습니다.

## 검증

반복 횟수, 1초 정지, 두 번의 전체 순환, 좌표 변환, 새 PNG 사용,
ESC/창 닫기, 오류 시 캔버스 정리를 검증하는 테스트 7개가 통과했습니다.
24개 프레임을 실제 pico2d로 렌더링하고 `main()`의 전체 순환도 직접 실행했습니다.
실제 측정한 네 번의 정지 시간은 각각 약 1.001초, 1.001초, 1.002초, 1.003초입니다.
전체 프레임의 사각형은 서로 겹치지 않고 이미지와 화면 안에 들어갑니다.
