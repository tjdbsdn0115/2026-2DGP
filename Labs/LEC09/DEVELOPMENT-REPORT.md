### 검증 방법과 발견 사항

- Python 표준 라이브러리 unittest로 5개 회귀 검사를 실행했다. 모든 동작의 반복·정지 경계, 무작위 5000개 시간 구간과 큰 시간 구간의 동등성, 픽셀·연결 영역 검사, 경로·오류 정리, 종료 입력·유효하지 않은 시간 검사가 통과했다.
- 첫 행의 세 번째와 네 번째 프레임은 불투명 픽셀의 x축 투영 영역이 맞닿는다. 실제 확대 캡처에서 인접 픽셀 혼입을 발견해 각각 `(58,39,28,39)`와 `(86,40,30,38)`로 보정했다. 수정 후 전체 픽셀 포함 검사와 연결 영역의 단일 프레임 소유 검사를 추가로 통과했다.
- 실제 화면의 76프레임 캡처는 `%TEMP%/sonic-gallery-1.png`, `%TEMP%/sonic-gallery-2.png`에 만들고 시각 확인했다. 각 파일은 시트 위쪽 5개 행과 아래쪽 5개 행을 순서대로 보여준다.
- 보이는 창으로 장시간 검사를 시도할 때 외부 SDL_QUIT 입력으로 중단된 실행이 있었다. 정지 중 창 닫기는 독립 실행으로 확인했다. 장시간 재생은 같은 SDL 캔버스를 숨긴 상태로 실행해 중단 없이 실제 시간으로 두 번 순환했다. 프로그램 자체의 기본 창 표시 동작은 유지했다.
- 검증용 스크립트와 임시 캡처는 `%TEMP%`에 두었다. 실행 코드와 프레임 데이터는 추가 모듈이나 JSON 없이 단일 Python 파일에 있다.
- 최종 Python 구문 검사와 `git diff --check`가 통과했다.

## 실행 방법

프로젝트 루트에서:

```powershell
python Labs/LEC09/soninc_animation_viewer.py
```

실행 파일 폴더에서:

```powershell
cd Labs/LEC09
python soninc_animation_viewer.py
```

창 닫기 또는 ESC로 종료한다. 기본 설정은 파일 상단의 캔버스 크기, SCALE, FRAME_INTERVAL, REPEAT_COUNT, PAUSE_SECONDS, EDGE_MARGIN 상수로 조정할 수 있다. 동작별 가로 속도와 점프 높이·주기는 ANIMATIONS의 speed, jump_height, jump_period로 조정한다. 파일명은 원본 PRE-PRD의 `soninc` 표기를 따른다.

커밋 수와 단계별 변경 확인:

```powershell
git rev-list --count b32b34f..HEAD
git log --reverse --oneline b32b34f..HEAD
```

단계별 표의 순서가 위 Git 로그 순서와 일치한다. 기본 뷰어는 첫 커밋 `e9053aa`부터 28단계까지 구현했다. 이동 기능 추가는 `66635f0`을 기준으로 29단계부터 기록한다.

## 이동 기능 추가 (2026-10-06)

후속 요청에 따라 이동 동작 8개에 위치 이동과 경계 반전을 추가하고, 공중 회전에는 점프 궤적을 적용했다. 가로 위치와 방향은 동작 전환 때 유지하며, 1초 정지 중에는 프레임과 위치를 함께 멈춘다. 실행 방법과 단일 파일 조건은 동일하다. 이동 정책은 PRD 5절에 기록했다. 기본 뷰어 28단계 이후 3개의 한글 커밋으로 구현·검증을 완료해 현재 전체 개발 커밋은 31개이다.

### 30단계 모의 검증

- 걷기·달리기 등 8종의 0.25초 이동 거리와 고정 2종의 위치 유지 확인.
- 왼쪽·오른쪽 경계 반전, 10번의 경계 통과 후 위치·방향 확인.
- 달리기 6초 종료 시 x=168에서 정지하고, 0.75초 정지 뒤 0.5초 갱신하면 남은 정지 0.25초와 빠른 달리기 0.25초를 구분해 x=114로 이동하는 것을 확인.
- 공중 회전 0.4초에 100픽셀 상승, 0.8초에 착지, 총 4초 후 5회 재생 완료·착지·정지 확인.
- 무작위 5000개 시간 구간과 같은 총 시간을 한 번에 갱신한 결과의 재생 상태·위치·방향·점프 시간 대조 통과.
- 0.009초 간격 12000번(108초) 검사에서 76프레임 전부 표시 영역 안에 있고 전체 2회 이상 순환함을 확인.
- 현재 좌표 출력과 수평 반전 시 기준점·종횡비 검사 통과. 기존 5개 검사도 모두 통과해 총 12개 회귀 검사를 확인했다.

### 변경된 프로그램의 실시간 통합 검증

`%TEMP%/sonic_integration.py --full`로 실제 SDL 캔버스에서 전체 두 번의 순환을 검사했다. 외부 창 닫기 입력을 피하도록 창을 숨긴 상태로 실제 시간 96초를 재생했다. 초기화·종료를 포함한 총 시간은 96.72초였고, 76프레임과 20번의 정지를 확인했다. 정지 시간은 0.995~1.007초였으며, 각 정지 진입 때 반복 계수 5와 마지막 프레임을 확인했다.

이동 동작 8개 모두에서 가로 위치 변화가 관찰되었고, 고정 동작 2개는 위치를 유지했다. 재생 중의 가로 위치는 경계 안에 있었으며, 정지 중에는 가로·세로 위치, 방향, 점프 시간이 변하지 않았다. 점프의 실측 최고 높이는 100.000픽셀이다. 전체 순환 완료 후 SDL_QUIT 이벤트 주입으로 정상 종료하고 캔버스를 정리했다.

기존 AC-01~AC-11 검증 근거와 기존 동작의 회귀 검사 결과를 유지하며, 추가 AC-12~AC-16을 모두 통과했다. 최종 변경의 `git diff --check`도 통과했다.
