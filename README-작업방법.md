# 2DGP 작업 저장소

모든 과제는 `tjdbsdn0115/2026-2DGP`에 저장합니다.

- 작업 폴더: `C:\Users\USER\2026-2DGP`
- GitHub: https://github.com/tjdbsdn0115/2026-2DGP
- `origin`: 내 저장소. 커밋 업로드와 다른 PC 작업 내려받기에 사용합니다.
- `upstream`: `unreal-class/2026-2DGP` 수업 원본. 강의 업데이트를 받습니다.
- 수업 원본으로의 푸시는 차단해 두었습니다.

## 사용 방법

- `push.bat`: 변경 내용을 커밋한 뒤 내 저장소로 업로드합니다.
- `pull.bat`: 내 저장소의 현재 브랜치 작업을 내려받습니다. 자동 재작성 없이 fast-forward만 허용합니다.
- `sync-fork.bat`: main에서 내 저장소를 먼저 내려받고, 수업 원본 업데이트를 병합한 뒤 내 저장소에 올립니다. 변경 파일이 있으면 먼저 커밋해야 합니다.

VS Code의 소스 제어에서도 main의 푸시·풀 대상은 `origin/main`입니다.
GitHub의 Sync fork 기능은 같은 수업 원본과 연결되어 있습니다. 로컬에서 동기화할 때는 `sync-fork.bat`를 사용할 수 있습니다.
